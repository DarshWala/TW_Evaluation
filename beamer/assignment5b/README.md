# Assignment 5 (Part 2) – Beamer Presentations

## What I Learned
- Using the `beamer` document class to create presentations
- Choosing a theme with `\usetheme{}`
- Choosing a color theme with `\usecolortheme{}`
- Creating frames (slides) with `\begin{frame}{Title}`
- Adding a title slide using `\titlepage`
- Using `\frametitle{}` for slide titles
- Adding bullet points inside frames using `itemize`
- Creating a table of contents slide with `\tableofcontents`
- Using blocks: `\begin{block}{Title}` for highlighted content

## Important Commands
| Command | Purpose |
|---------|---------|
| `\documentclass{beamer}` | Beamer presentation class |
| `\usetheme{Warsaw}` | Set presentation theme |
| `\usecolortheme{dolphin}` | Set color theme |
| `\begin{frame}{Title}` | Create a slide |
| `\titlepage` | Render the title slide |
| `\tableofcontents` | Table of contents slide |
| `\begin{block}{Name}` | Highlighted block |
| `\pause` | Reveal items step by step |
