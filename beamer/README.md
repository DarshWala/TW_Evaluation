# Beamer

Beamer is a LaTeX document class for creating professional presentations (slides). It allows the same LaTeX skills used for documents to be applied to slide decks, with built-in themes, overlays, and structured frames.

## Assignment 5b
**Creating a Presentation with Beamer**

Learned to create a multi-slide presentation using the `beamer` class. Covered choosing themes (`\usetheme`) and color themes (`\usecolortheme`), creating frames with `\begin{frame}`, adding a title slide with `\titlepage`, inserting a table of contents, using `itemize` inside slides, and highlighting content with `\begin{block}`.

## Key Concepts

| Concept | Command |
|---------|---------|
| Presentation class | `\documentclass{beamer}` |
| Theme | `\usetheme{Warsaw}` |
| Color theme | `\usecolortheme{dolphin}` |
| A slide | `\begin{frame}{Title}` |
| Title slide | `\titlepage` |
| Highlighted block | `\begin{block}{Name}` |
| Step-by-step reveal | `\pause` |
