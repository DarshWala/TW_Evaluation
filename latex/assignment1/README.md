# Assignment 1 – Hello World & LaTeX Basics

## What I Learned
- How to create a basic LaTeX document using `\documentclass{article}`
- The structure: `\begin{document}` ... `\end{document}`
- How to compile a `.tex` file to produce a PDF
- Adding sections and subsections with `\section{}` and `\subsection{}`
- Adding a Table of Contents with `\tableofcontents`
- Changing font size via document class options: `\documentclass[12pt]{article}`
- Changing paper size: `\documentclass[a4paper]{article}`
- Creating numbered lists with the `enumerate` environment
- Inline math mode: `$e = mc^2$`

## Important Commands
| Command | Purpose |
|---------|---------|
| `\documentclass[options]{class}` | Set document class and options |
| `\begin{document}` / `\end{document}` | Document body wrapper |
| `\section{Title}` | Add a section |
| `\subsection{Title}` | Add a subsection |
| `\tableofcontents` | Generate table of contents |
| `\begin{enumerate}` / `\item` | Numbered list |
| `$...$` | Inline math mode |
