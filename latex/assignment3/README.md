# Assignment 3 – Math Environments

## What I Learned
- Using the `equation` environment for numbered equations
- Using `\overbrace` and `\underbrace` for annotating expressions
- Creating matrices with the `array` environment inside `\[ \]`
- Using `bmatrix`, `pmatrix` for different bracket types
- Writing piecewise functions with the `cases` environment
- Using `\sum`, `\sqrt`, `\frac` for mathematical notation
- Using `amsmath` package for advanced math
- Creating aligned multi-line equations

## Important Commands
| Command | Purpose |
|---------|---------|
| `\begin{equation}` | Numbered equation |
| `\overbrace{...}^{label}` | Overbrace with label |
| `\underbrace{...}_{label}` | Underbrace with label |
| `\begin{cases}` | Piecewise function |
| `\begin{bmatrix}` | Matrix with square brackets |
| `\frac{num}{den}` | Fraction |
| `\sum_{i=1}^{n}` | Summation |
| `\sqrt{x}` | Square root |
| `\usepackage{amsmath}` | Advanced math support |
