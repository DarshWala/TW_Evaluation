# Google Docs

Google Docs is a cloud-based word processor from Google Workspace that enables real-time collaborative editing, rich formatting, and easy sharing of documents from any device.

## Key Features

- Real-time multi-user editing — see collaborators' cursors and changes live
- Comments, suggestions, and tracked edits for review workflows
- Automatic saving — no manual save needed
- Access from any device via browser

---

## Document Structure & Formatting

- Use **Heading styles** (Heading 1, 2, 3…) for consistent hierarchy — enables an auto-generated Table of Contents
- Insert tables via Insert → Table
- Insert images from Drive, URL, upload, or camera
- Insert → Drawing for simple diagrams
- Insert → Equation for basic LaTeX-style math
- Bulleted/numbered lists and checklists available in the toolbar
- Customize headers, footers, and page numbering via Insert menu

---

## Collaboration

- Click **Share** → invite via email or link; set View / Comment / Edit permissions
- Use **Suggesting mode** (like Track Changes) for proposed edits
- Comments can be assigned to specific people and resolved when addressed
- Integrated chat for live discussion within the document

---

## Version History

- File → **Version history** → See version history to browse all past saves
- Restore any previous version with one click
- Name important versions (e.g., "Submitted Draft") for quick access

---

## Citations & Bibliography

- Tools → **Citations**: supports MLA, APA, and Chicago styles
- Insert in-text citations and auto-generate a bibliography section
- Compatible with Zotero and Mendeley via add-ons

---

## Export Options

| Format | How |
|--------|-----|
| PDF | File → Download → PDF |
| Word (.docx) | File → Download → Microsoft Word |
| Plain text | File → Download → Plain text |
| Publish to web | File → Share → Publish to web |

## Doxygen vs Google Docs

| Feature | Doxygen | Google Docs |
|---------|---------|-------------|
| Purpose | Code / API documentation | General documents, proposals, reports |
| Collaboration | Indirect (via code review) | Real-time multi-user editing |
| Output | HTML, PDF, LaTeX | PDF, DOCX, Web |
| Best For | Source code, APIs, libraries | Policies, specs, meeting notes, reports |
