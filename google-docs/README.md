# Google Docs – Notes

## What I Learned

### Key Features
- Cloud-based word processor — accessible from any device
- Real-time collaborative editing with multiple users simultaneously
- Comments, suggestions, and tracked changes for review
- Automatic version history (File → Version history)

### Document Structure
- Use **Heading styles** (Heading 1, 2, 3...) for consistent hierarchy
- Proper heading use enables auto-generated Table of Contents
- Templates available for reports, meeting notes, project proposals

### Collaboration
- Share via "Share" button — set View / Comment / Edit permissions
- Use "Suggesting" mode for tracked edits (like Track Changes in Word)
- Comments can be assigned to specific collaborators
- Live cursors show where each collaborator is editing

### Formatting Features
- Insert → Table for data organization
- Insert → Image (from Drive, URL, upload, or camera)
- Insert → Drawing for simple diagrams
- Insert → Equation for basic LaTeX-style math
- Bulleted/numbered lists and checklists
- Custom headers, footers, and page numbering

### Citations
- Tools → Citations: supports MLA, APA, Chicago styles
- Auto-generate bibliography from citations
- Compatible with Zotero and Mendeley via add-ons

### Export Options
- Download as PDF, DOCX, ODT, HTML, or plain text
- Publish to web for public access
- Integrates with Google Slides and Sheets

### Best Practices
- Use heading styles consistently — not just bold text
- Name important document versions (File → Version history → Name this version)
- Resolve comments after addressing them
- Keep sharing permissions minimal (principle of least privilege)

## Doxygen vs Google Docs

| Feature | Doxygen | Google Docs |
|---------|---------|-------------|
| Purpose | Code/API documentation | General documents, proposals |
| Collaboration | Indirect (code reviews) | Real-time multi-user |
| Output | HTML, PDF, LaTeX | PDF, DOCX, Web |
| Best For | Source code, APIs | Reports, notes, specs |
